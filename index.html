About ParkEase

Modern, lightweight Parking Management Web Application with Monthly Payments.

🚗 Project Overview

ParkEase is a full-featured, zero-dependency Parking Management System crafted using pure HTML5, CSS3, and Vanilla JavaScript. It manages daily parking, monthly subscriptions, simulated payment processing (UPI, Card, Cash), and revenue reporting, persisting all data directly in the browser via the LocalStorage API.

💳

Monthly Subscriptions

Automated 30-day passes with dynamic pricing for bikes (₹500), cars (₹1,500), premium slots (₹2,000), and heavy vehicles (₹3,000).

🛡️

Payment Simulation

Realistic simulated checkout interface supporting UPI, Debit/Credit Card, and Cash without processing real funds.

🖨️

Printable Receipts

Clean, professional payment receipts with unique Payment and Subscription IDs ready for instant browser printing.

⏳

Expiry Tracking & Renewal

Real-time subscription lifecycle tracking (Active, Expiring Soon, Expired) with one-click instant renewal.

📊

Admin Revenue Reports

Comprehensive administrative analytics displaying daily/monthly earnings, transaction logs, and pure CSS charts.

💾

Zero Backend Needed

100% client-side execution ready for GitHub Pages hosting without requiring Node.js, PHP, or external databases.
